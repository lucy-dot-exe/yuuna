# npm

A real local dev setup for Yuuna — TypeScript, type-checking, and a dev
server with hot reload, via [Vite](https://vitejs.dev). Nothing
Yuuna-specific about the tooling here; swap Vite for whatever bundler
you already use if you'd rather.

## Use it

```sh
npm install
npm run dev
```

Then open the URL Vite prints. Edit `src/main.ts` and save — the page
updates on its own.

## Want zero install instead?

See the [`blank`](../blank) template — a single `index.html` that runs
straight from a CDN, no `npm install` required.
