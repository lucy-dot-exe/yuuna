# Templates

Starting points for a new Yuuna project — pick whichever matches how
you want to work, copy the folder, and go.

- **[blank](blank)** — a single `index.html`, zero install. Open it in
  a browser and it runs.
- **[npm](npm)** — TypeScript + a dev server with hot reload (via
  [Vite](https://vitejs.dev)), for a real local project.
- **[neutralino-desktop](neutralino-desktop)** — the `npm` template's
  TypeScript + Vite setup, wrapped in
  [Neutralino](https://neutralino.js.org) to run as a native desktop
  window instead of a browser tab.

See the main [README](https://github.com/lucy-dot-exe/yuuna#templates)
for how to grab one.
